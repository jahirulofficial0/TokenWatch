TokenWatch Settings

RATE LIMIT WINDOW

The countdown in the popup and the corner widget runs from the window start. TokenWatch cannot reset a provider's own server-side limit — this timer tracks the window so you can see when it ends. A detected limit message also starts a fresh window automatically.

PROJECTS

Usage tracked on AI sites is credited to the active project selected in the popup. Renaming a project keeps its history.

DATA

All figures are local estimates stored only in this browser (page text length ÷ 4). Nothing is uploaded anywhere.
